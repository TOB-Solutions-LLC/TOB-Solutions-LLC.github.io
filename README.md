2. Open `index.html` in a web browser
3. The site will be live at `https://tob-solutions-llc.github.io`

## File Descriptions

### script.js

## Customization

### Update Contact Email
In `script.js`, update the email address in the form handler:
```javascript
const mailtoLink = `mailto:your-email@example.com?...`;
```

### Modify Services
Edit the service cards in `index.html` section to update descriptions and icons.

### Change Brand Colors
Update the CSS variables in `styles.css`:
```css
:root {
    --charcoal-gray: #36454F;
    --pantone-2945: #003366;
    --pantone-108: #FFC900;
}
```
